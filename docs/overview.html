Overview

BeanieOS is a bare-metal x86-64 hobby kernel implemented entirely in Rust. It operates without a standard library (#![no_std]) and without an operating system runtime environment (#![no_main]). The kernel boots via Multiboot2 compliant bootloaders, configures foundational CPU structures (GDT, IDT, paging), initializes a memory heap and graphical framebuffer, and hands control over to a cooperative async task executor.

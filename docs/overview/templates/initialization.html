Purpose and Scope

This section provides a high-level overview of the boot and initialization sequence for BeanieOS, tracing the execution path from UEFI firmware execution to the handoff into the kernel's main execution loop. For comprehensive implementation details, refer to the child pages:

  • Firmware, Limine and Disk Image
  • Assembly Entry and Linker Layout
  • kernel_main and Subsystem Init Order

High-Level Boot-to-Kernel Flow

The machine boots UEFI using the limine bootloader, which loads the kernel image using the Multiboot2 specification, parses onfiguration options from limine/limine.conf, and hands control over to the kernel entry point in long mode.

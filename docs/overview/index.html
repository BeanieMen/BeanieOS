Current Status

BeanieOS is an experimental Rust-based operating system with a functioning kernel, interrupt handling, memory management, a basic process system, and a command-line shell. Its graphical framebuffer is working, and FAT32 filesystem and storage read/write support are implemented. Development is focused on standardizing the process system, expanding shell functionality, and building out userspace.

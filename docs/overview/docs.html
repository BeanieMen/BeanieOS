Overview

BeanieOS is a bare-metal x86_64 hobby kernel implemented entirely in Rust. It operates without a standard library (#![no_std]) and without an operating system runtime environment (#![no_main]). The kernel boots via Multiboot2 compliant bootloaders, configures foundational CPU structures (GDT, IDT, paging), initializes a memory heap and graphical framebuffer, and hands control over to a cooperative async task executor.

System Architecture Map

The codebase is organised into modular subdirectories corresponding to core kernel esponsibilties, anchored by src/main.rs as the primary entry and orchestration point.

Boot-to-Executor Flow

The initialization sequence transitions the processor from early bootloader handoff into fully interactive kernel tasks. The control flow begins at kernel_main, invokes init to setup paging, allocation, graphics, and interrupts, and finally spawns asynchronous tasks into Executor::run.

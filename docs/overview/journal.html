Development Journal

Purpose and Scope

This page summarizes the evolutionary milestones, technical hudles, and design decisions recorded in the project's development journal (JOURNAL.md). It traces the trajectory of BeanieOS from initial concept and legacy VGA restrictions to a modern x86_64 bare-metal kernel featuring a graphic framebuffer, CPU exception handling, interrupt controllers, and automated build tooling.

1. Framebuffer Transition and Graphics Output

Early milestones focused on abandoning the legacy 80x25 VGA text mode in favour of a modern graphics framebuffer. This ransition required inegrating bootloader protocols (Multiboot2/Limine) to pass framebuffer metadata (resolution, pitch, and pixel format) directly to the kernel initialization routines.

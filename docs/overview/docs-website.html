Documentation Website (docs/)

The docs/ directory contains the static website for BeanieOS, published at beanie-os.vercel.app. This website serves as the primary documentation portal, providing an overview of the kernel, getting started guides, dependency information, and a development journal. The site s built by using standard web technologies: HTML for structure and CSS for styling.

Website Structure and Content

The documentation website is composed of several key HTML files and a ingle CSS stylesheet. The index.html file serves as the homepage, offering general introduction to BeanieOS, its current development status, and a roadmap for future work, The docs.html file provides a high-level overview f the kernel's architecture and boot process, acting as a central hub for more detailed documentation pages.

Homepage index.html

The index.html file is the entrypoint to the BeanieOS website. It features:

  • A navigation bar (.nav-bar) with links to the documentationand the Github repository.
  • An introductory section (.intro) describing BeanieOS as an x86_64 hobby kernel written in Rust.
  • A "Current Status" section (.current-status) detailing the progress of various core system omponents like the bootloader, kernel, interrupt handling, memory management, basic process system, and shell.
  • Sections for "Graphics", "Storage & File System", and "Architecture", outlining the current state of these subsystems.
  • A "Next Up" section ( .next) listing future development goals .
  • A "Learn BeanieOS" section (.documentation) with a link to the main documentation page (docs.html).

Overview Page (docs.html)

This page provides more technical introduction to BeanieOS . It covers:

  • A general overview of BeanieOS as a bare-metal x86_64 kernel implemented in Rust, highlighting its #![no_std] and #![no_main] characteristics.
  • A "System Architecture Map"section, indicating that the codebase is organized into modular subdirectories with src/main.rs as the primary entry point.
  • A "Boot-to-Executor Flow" section, describing the initialization sequence from kernel_main to Executor::run
  • A "Child Pages" section, linking to more specific documentation pages:
  • "Getting Started & Build System" (overview/getting-started.html).
  • "Dependencies and Crate Configuration" (overview/dependencies.html).
  • "Developer Journal" (overview/journal.html).

Styling

The style.css file defines the visual presentation of the website. It uses the "Google Sans Code" font and applies styles to the navigation bar, headings, paragraphs, and various sections to create a consistent look and feel. Key styling elements include:

  • Global body styles for font and margins.
  • Navigation bar (.nav-bar) styling, including background color, display properties, and link appearance.
  • Section margins
  • Specific styles for the introductory section (.intro), bordered headings (.bordered-heading), and margined lines (.margined-lines).
  • Status indicators (.status) for development progress.

Deployment

The documentation website is published at beanie-os.vercel.app. This indicates that Vercel is used for hosting and deployment, likely configured to serve the static files directly from the docs/ directory.

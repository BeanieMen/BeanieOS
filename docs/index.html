An operating system written in Rust

You've reached the website for BeanieOS - a lightweight, experimental operating system built with Rust.

Currently targeting x86_64 architecture.

Follow the project as we explore operating system development from scratch!

Current Status

BeanieOS is under active development. The core foundations of the operating system are now functional, with development moving towards processes, storage, userspace, and eventually a more complete system environment.

Core System

Bootloader - Done
Kernel - Functional
Interrupt Handling - Functional
Memory Management - Functional
Basic Process System - Working, currently non-standard
Shell - Basic commands working

Graphics

Native Graphical Framebuffer - Working
Graphics Driver - Non-VESA implementation working

Storage & File System

Storage Drivers - Read/Write working
FAT32 Filesystem - Read/Write working

Architecture

x86_64 - Current target
Monolithic Kernel - Current architecture

Next Up

- Standardize the process system
- Expand shell commands
- Improve filesystem support and reliability
- Build out userspace
- Continue hardware/driver support

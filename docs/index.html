Writing an OS in Rust

This blog series creates a small operation system in the Rust programming language. Each post is a small tutorial that includes all needed code, so you can follow along if you like.

The first step in creating our own operating system is to create a Rust executable that does not link the standard library. This makes it impossible to run rust code on the bare metal without an underlying operating system. read more >>

A Minimal Rust Kernel

In this post, we create a minimal 64-bit Rust kernel for the x84 architecture. We build upon the freestanding Rust binary from the previous post to create a bootable disk image that prints something to the screen. read more >>

VGA Text Mode

The VGA text mode is a simple way to print text to the screen. In this post, we create an interface that makes its usage safe and simple by encapsulating all unsafety in a separate module. We also implement support for Rust's formatting macros. read more >>

Testing

This post explores unit integration testing in no_std executables. We will use Rust's support for custom test frameworks to execture test functions inside our kernel. To report the results out of QEMU, we will use different features of QEMU and the bootimage tool. read more >>

CPU Exceptions

CPU exceptions occur in various erroneus situations, for example, when accessing an invalid memory address or when dividing by zero. To react to them, we have to set up an interrupt descripter table that provides handler functions. At the end of this post, our kernel will be able to catch breakpoint exceptions and resume normal execution afterward. read more >>

Double Faults

This post explores the double fault exceptions in detail, which occurs when the CPU fails to invoke an exceptions handler. By handling this this exception, we avoid fatal triple faults that cause a system reset. To prevent triple faults in all cases, we also set up an Interrupt Stack Table to catch double faults on a separate kernel stack. read more >>
